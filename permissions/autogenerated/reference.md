## Default Permission

All the commands of the PDF view

#### This default permission set includes the following:

- `allow-open`
- `allow-frame`
- `allow-cover`
- `allow-close`
- `allow-find`
- `allow-zoom`
- `allow-go`
- `allow-back`
- `allow-forward`
- `allow-page-to`
- `allow-turn`
- `allow-selection`
